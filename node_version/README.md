# Node Version — Trend Rider

This folder contains a minimal Node.js scaffold that mirrors the Python trading bot logic.

Quick start
1. From this folder, install dependencies:
   ```bash
   cd node_version
   npm install
   ```
2. Copy your `.env` from the Python project root into `node_version/` (or update env vars).
3. Run:
   ```bash
   npm start
   ```

Notes
- This is a working scaffold implementing core trader, notifier, symbol utils and simplified indicators.
- It is intentionally small so you can iterate and extend it to fully match Python behaviour.
